# Screening Protocol: Quantized Model Reasoning Benchmarking

## Review Objective
To identify empirical evaluations of quantized models under 3B parameters tested on reasoning tasks.

## Eligibility Criteria

### Inclusion Criteria
- Study includes an empirical evaluation of a machine learning model.
- Model parameter size is < 3 billion parameters.
- Model is quantized (e.g., FP8, INT4).
- Task involves reasoning capabilities (e.g., mathematical, logical, chain-of-thought, or complex reasoning tasks).

### Exclusion Criteria
- Models >= 3B parameters.
- Studies focused only on training, without empirical evaluation of reasoning performance.
- Non-reasoning tasks (e.g., image generation, basic language modeling without explicit reasoning).

### Population
Machine learning models (specifically quantized models < 3B parameters).

### Intervention / Index Test
Quantization techniques (specifically comparing precision levels like FP8, INT4).

### Outcome
Reasoning performance metrics (e.g., accuracy on benchmarks, reasoning depth).
